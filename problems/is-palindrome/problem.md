# Palindrome check

Read one line. Ignoring case and every character that is not a letter or digit, is it a palindrome? Print `YES` or `NO`.

## Input
One line of up to 500 000 printable ASCII characters.

## Output
`YES` or `NO`.

## Example
Input:
```
A man, a plan, a canal: Panama
```
Output:
```
YES
```
