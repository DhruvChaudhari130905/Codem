# Longest climb

Given `n` integers, find the length of the longest strictly increasing subsequence (not necessarily contiguous).

## Input
The first line has `n` (1 ≤ n ≤ 120 000). The second line has `n` integers, each between −10⁹ and 10⁹.

## Output
A single integer.

## Example
Input:
```
8
10 9 2 5 3 7 101 18
```
Output:
```
4
```
