# Best streak

Given `n` integers, find the largest possible sum of a non-empty contiguous subarray.

## Input
The first line has `n` (1 ≤ n ≤ 80 000). The second line has `n` integers, each between −10⁹ and 10⁹.

## Output
The maximum subarray sum.

## Example
Input:
```
9
-2 1 -3 4 -1 2 1 -5 4
```
Output:
```
6
```
