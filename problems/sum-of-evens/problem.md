# Sum of even numbers

Given `n` integers, print the sum of the even ones.

## Input
The first line has `n` (1 ≤ n ≤ 80 000). The second line has `n` integers, each between −10⁹ and 10⁹.

## Output
The sum of the even integers (0 if there are none).

## Example
Input:
```
5
1 2 3 4 5
```
Output:
```
6
```
